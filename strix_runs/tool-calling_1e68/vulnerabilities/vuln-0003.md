# Mutable GitHub Actions references in workflow files

**ID:** vuln-0003
**Severity:** MEDIUM
**Found:** 2026-07-26 03:37:45 UTC
**Target:** /workspace/Tool-Calling/.github/workflows/
**CWE:** CWE-829
**CVSS:** 4.2
**Fix Effort:** Trivial

## Description

GitHub Actions workflow files use mutable tag references (e.g., actions/checkout@v4, actions/setup-node@v4) instead of pinned commit SHAs, exposing the CI/CD pipeline to supply-chain attacks.

## Evidence

From .github/workflows/deploy-pages.yml:
```yaml
- name: Checkout repository
  uses: actions/checkout@v4

- name: Setup Node.js
  uses: actions/setup-node@v4
  with:
    node-version: '20'
```

Similar patterns found in sync-stars.yml and trending-weekly.yml.

## Impact

If an attacker compromises a GitHub Action repository or if the action maintainer's account is taken over, the mutable @v4 reference could be updated to point to a malicious version, enabling code execution in the CI/CD pipeline with repository write permissions.

## Technical Analysis

Three GitHub Actions workflow files use mutable tag references:

1. `.github/workflows/deploy-pages.yml` - uses `actions/checkout@v4`, `actions/setup-node@v4`, `actions/upload-pages-artifact@v3`, `actions/deploy-pages@v3`
2. `.github/workflows/sync-stars.yml` - uses `actions/checkout@v4`, `actions/setup-node@v4`
3. `.github/workflows/trending-weekly.yml` - uses `actions/checkout@v4`, `actions/setup-node@v4`

These mutable references can be silently repointed by the action owners, enabling supply-chain attacks. The recommended practice is to pin references to full 40-character commit SHAs.

## Proof of Concept

1. Review .github/workflows/deploy-pages.yml for mutable action references.
2. Observe that actions/checkout@v4 and actions/setup-node@v4 are used without SHA pinning.
3. Verify that these tags can be moved by action maintainers, unlike fixed commit SHAs.

```
# Check workflow files for mutable references
grep -r "uses:.*@" /workspace/Tool-Calling/.github/workflows/*.yml | grep -v "@[0-9a-f]\{40\}"
```

## Remediation

Pin all GitHub Action references to their full 40-character commit SHA instead of mutable tags. For example, change actions/checkout@v4 to actions/checkout@b4ffde65f16936253d0b0a9c6d5a3e8e7c1d2f3a. Use tools like renovate bot or dependabot with the sha pinning option to automate this process.

## Assumptions

Assumes the GitHub Actions ecosystem is trusted but acknowledges historical supply-chain compromises of popular actions (trivy-action, kics-github-action).
