### 重要教訓（可遷移）
**「Tier-3 啟發命中的最鄰近身分」絕不可自動落盤**。Tier-3 是「僅供參考」層級，其命中常是詞彙偽影（如 langchain 因 RAG 觸發「知識管理」、graft 因「coding agent」觸發「AI 代理」）。落盤前必須：
1. 通過語意相關性門（與現行分類功能緊鄰）
2. 查證官方 description 確認工具**本身身分**（而非「服務於某身分」）
3. 任一關不通過 → 維持現行，留人審

`ontology-ontio` 事故：憑 id 名稱「ontology」推測為知識圖譜平台，未查 description 就落盤「知識管理」——實際是區塊鏈協議。**任何「身分落盤」前必查官方 description，不可憑名稱推測。**
