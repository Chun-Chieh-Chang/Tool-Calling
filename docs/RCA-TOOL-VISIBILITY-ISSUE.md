## 根本原因分析

### 直接原因
`dist/registry/tools.json` 未同步更新。

```
registry/tools.json       → 563 個工具 ✅ (已更新)
dist/registry/tools.json  → 513 個工具 ❌ (未更新)
```

### 流程缺陷
1. **缺失 CI/CD 自動構建**：GitHub Actions 未在 push 時自動執行 `npm run build`
2. **無預提交檢查**：git commit 前未驗證 dist/ 是否同步
3. **手動流程易失誤**：開發者可能忘記在建構階段重建 dist/

### 預防措施（已實現）

#### 1. 分類一致性檢查腳本
```bash
node scripts/check-category-consistency.js          # 檢查全部
node scripts/check-category-consistency.js --recent # 僅檢查最近 24h
node scripts/check-category-consistency.js --hours 48 # 檢查最近 48h
```

#### 2. Git pre-commit hook (Windows 相容版本)
```batch
REM .git/hooks/pre-commit.bat
@echo off
echo "🔍 執行分類一致性檢查..."
node scripts/check-category-consistency.js --recent || echo "⚠️ 發現潛在問題"
exit 0
```

#### 3. 批量添加工具的 SOP
```bash
# 1. 執行批量添加腳本
node batch-add-repos.cjs

# 2. 運行 validate
node cli.js validate

# 3. 檢查分類一致性
node scripts/check-category-consistency.js

# 4. 重建 dist
npm run build

# 5. 確認 dist 更新
node -e "console.log(require('./dist/registry/tools.json').tools.length)"

# 6. Commit 並推送
git add -A
git commit -m "feat: ..."
git push origin main
```
